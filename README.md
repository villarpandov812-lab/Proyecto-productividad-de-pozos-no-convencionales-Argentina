# Proyecto productividad de pozos no convencionales Argentina
Proyecto final Energía Digital Data Science de Fundación YPF:Desarrollar un modelo que clasifique los pozos petrolíferos no convencionales en alta o baja productividad, utilizando características disponibles al inicio de su vida productiva (como la ubicación geográfica, formación geológica, empresa operadora, año de inicio de producción y profundidad).
